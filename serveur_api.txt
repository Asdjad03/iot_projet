# Partie 2 : Serveur FastAPI

###Exercice 1 : remplissage de la base de données
# Description
On met en place un serveur FastAPI pour gérer les données de mesures et de factures liées aux logements. Il expose des API REST permettant de consulter et d'ajouter des données via des routes dédiées.

# Emplacement
Fichier concerné : `python/remplissage_2.py`

# Fonctionnalités principales
Routes pour les mesures :
GET /mesures : Retourne toutes les mesures enregistrées dans la base.
POST /mesures : Ajoute 5 mesures aléatoires pour chaque capteur en fonction de leur type (température, humidité, etc.).

Routes pour les factures :
GET /factures : Retourne toutes les factures enregistrées dans la base.
POST /factures : Ajoute des factures aléatoires pour chaque type de manière à avoir des valeurs cohérentes (électricité, eau, gaz, déchets) dans tous les logements.

###Exercice 2 : serveur web

On étend les fonctionnalités du serveur FastAPI en ajoutant un affichage des données sous forme graphique grâce à l'intégration de Google Charts. Ce serveur web offre également la possibilité de visualiser les mesures et factures, tout en ajoutant des données aléatoires.

# Emplacement
Fichier concerné : `python/remplissage_3.py`

# Fonctionnalités principales
Routes pour les mesures :
GET /mesures : Retourne toutes les mesures enregistrées dans la base.
POST /mesures : Ajoute 5 mesures aléatoires pour chaque capteur en fonction de leur type (température, humidité, etc.).

Routes pour les factures :
GET /factures/camembert :
Génère une page HTML affichant un diagramme en camembert des types de factures et leurs montants totaux.
Utilise Google Charts pour visualiser les données.
POST /factures : Ajoute des factures aléatoires pour chaque type (électricité, eau, gaz, déchets, chauffage) dans tous les logements.
